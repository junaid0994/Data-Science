🚀 Getting Started

Follow these steps to explore and run the notebooks on your local machine.

1. Clone the repository
git clone https://github.com/junaid0994/Data-Science.git

2. Navigate to the project directory
cd Data-Science

3. Install the required libraries
python -m pip install numpy matplotlib seaborn jupyter

4. Launch Jupyter Notebook
jupyter notebook


Open any .ipynb file in the Jupyter interface and start exploring the code.
